# Directives (Layer 1: What to do)

This directory contains Standard Operating Procedures (SOPs) written in Markdown.

## Directive Structure Guidelines

Each directive should define:
1. **Goal**: High-level purpose and objective.
2. **Inputs**: Required parameters, datasets, or user inputs.
3. **Execution Tools**: Python scripts in `execution/` to call.
4. **Outputs / Deliverables**: Resulting artifacts, cloud sheets/slides, or reports.
5. **Edge Cases & Error Handling**: Learned constraints, API limits, and fallback strategies.
